# Welcome

Welcome to the **[__PROJECT_SLUG__]** documentation. This starter is intentionally complete enough to edit, navigate, search, and publish from the first day.

## Start the Site

Run the workspace development command from the monorepo root:

```bash
npm run dev --workspace "[__WORKSPACE_PACKAGE_NAME__]"
```

Open the local URL printed by Docusaurus, then edit this page and watch the browser update.

## Where to Edit

- Add guides in `docs/`.
- Organize the documentation sidebar in `sidebars.ts`.
- Configure the navbar, footer, identity, and selected Nova preset in `docusaurus.config.ts`.
- Keep project-wide identity in the root `nova.config.json` so generated metadata stays aligned.
