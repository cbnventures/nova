Lint `.astro` components with Nova's complete Astro adapter. The preset owns the parser, TypeScript frontmatter parser, Astro processor, framework globals, generated-directory ignore, plugin registration, and a focused correctness baseline.

## Usage

Spread `fwAstro` after the language layers. You do not need to import `eslint-plugin-astro` yourself.

```ts title="eslint.config.mts"
import {
  dxCodeStyle,
  dxIgnore,
  fwAstro,
  langJavascript,
  langTypescript,
  runtimeBrowser,
} from '@cbnventures/nova/presets/eslint';

export default [
  ...dxIgnore,
  ...dxCodeStyle,
  ...langJavascript,
  ...langTypescript,
  ...fwAstro,
  ...runtimeBrowser,
];
```

## What This Preset Configures

- Ignores Astro's `.astro` generated directory.
- Parses component files with `astro-eslint-parser` and TypeScript frontmatter with `typescript-eslint`.
- Declares Node, `Astro`, and `Fragment` globals available to Astro components.
- Registers Astro's processor and curated compile, directive, deprecation, and unused-style checks.

Nova intentionally selects the framework checks it can compose reliably instead of copying Astro's entire opinionated preset.
