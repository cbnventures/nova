Configure TypeScript for Vue single-file components and a bundler-owned build.

## Usage

```json title="tsconfig.json"
{
  "extends": [
    "@cbnventures/nova/presets/tsconfig/dx-essentials.json",
    "@cbnventures/nova/presets/tsconfig/dx-strict.json",
    "@cbnventures/nova/presets/tsconfig/runtime-browser.json",
    "@cbnventures/nova/presets/tsconfig/fw-vue.json"
  ],
  "include": [
    "./src/**/*"
  ]
}
```

## Compiler Options

| Option             | Value                               | Purpose                                                        |
|--------------------|-------------------------------------|----------------------------------------------------------------|
| `isolatedModules`  | `true`                              | Keeps every file safe for independent bundler transforms.      |
| `jsx`              | `"preserve"`                        | Leaves JSX for Vue's build tooling.                            |
| `lib`              | `["DOM", "DOM.Iterable", "ESNext"]` | Provides browser and modern JavaScript APIs.                   |
| `module`           | `"ESNext"`                          | Preserves ECMAScript modules for the bundler.                  |
| `moduleResolution` | `"Bundler"`                         | Resolves package exports the way a modern bundler does.        |
| `noEmit`           | `true`                              | Keeps TypeScript as the checker while the bundler owns output. |
