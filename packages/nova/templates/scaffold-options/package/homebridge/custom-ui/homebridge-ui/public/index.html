Custom UI

Explore a Homebridge-native custom settings interface, then replace the examples with controls for your plugin.

What this starter includes

The generated package combines a dynamic Homebridge platform, a schema-backed configuration form, and an optional custom UI server.

  • Host-owned Bootstrap styling and color modes
  • Responsive tabs and accessible form examples
  • A separate native configuration mode

How to customize it

Keep only the controls your plugin needs, connect them to window.homebridge, and validate configuration before updating it.

Tip: The examples are interactive inspiration. They do not write demonstration values into a user's Homebridge configuration.

These controls demonstrate Bootstrap's Homebridge-themed input styles without saving their sample values.
