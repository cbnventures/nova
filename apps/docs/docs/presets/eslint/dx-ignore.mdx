Exclude project-owned supporting files, build output, source maps, and generated files from ESLint while retaining the documentation that explains the root `assets` folder.

## Why Use This Preset?

1. Skips project-owned working files beneath the root `assets` folder while continuing to lint `assets/README.md`.
2. Skips `dist`, `build`, `out`, and `.output` directories so compiled artifacts never trigger lint failures.
3. Drops `**/*.map` source maps and `generated`/`__generated__` folders so machine-written code stays out of your reports.
4. Ignores Next.js `.next` output, the generated `next-env.d.ts`, and Wrangler state so framework tooling does not add noise.
5. Sits first in the layer order so every later <Terminology title="config layer" to="/docs/quickstart/terminology#nova-concepts" color={true}>preset</Terminology> inherits a clean file set.

## Usage

Spread `dxIgnore` first in your <Terminology title="single-file config" to="/docs/quickstart/terminology#builds-and-tooling" color={true}>flat config</Terminology>, ahead of the code style, language, and runtime layers.

```ts title="eslint.config.mts"
import {
  dxCodeStyle,
  dxIgnore,
  langTypescript,
  runtimeNode,
} from '@cbnventures/nova/presets/eslint';

export default [
  ...dxIgnore,
  ...dxCodeStyle,
  ...langTypescript,
  ...runtimeNode,
];
```

## What This Preset Configures

The preset registers no plugins, parsers, or rules — it defines five named ignore groups, each scoped with glob patterns. Because they only exclude files, the groups apply globally rather than targeting a specific set of script extensions.

### Assets

| Pattern             | Excludes                                                                 |
|---------------------|--------------------------------------------------------------------------|
| `assets/**/*`       | Project-owned supporting files beneath the root `assets` folder.         |
| `!assets/README.md` | Re-includes the root assets guide so its documentation remains lintable. |

The root-relative patterns do not ignore folders such as `src/assets`, so application assets inside source trees remain linted.

### Build output

| Pattern         | Excludes                                 |
|-----------------|------------------------------------------|
| `**/dist/**`    | The `dist` compiled output directory.    |
| `**/build/**`   | The `build` compiled output directory.   |
| `**/out/**`     | The `out` compiled output directory.     |
| `**/.output/**` | The `.output` compiled output directory. |

### Generated

| Pattern               | Excludes                                      |
|-----------------------|-----------------------------------------------|
| `**/*.map`            | Source map files emitted alongside output.    |
| `**/generated/**`     | The `generated` folder of machine output.     |
| `**/__generated__/**` | The `__generated__` folder of machine output. |

### Next

| Pattern            | Excludes                                    |
|--------------------|---------------------------------------------|
| `**/.next/**`      | The Next.js `.next` build cache.            |
| `**/next-env.d.ts` | The generated Next.js `next-env.d.ts` file. |

### Wrangler

| Pattern           | Excludes                          |
|-------------------|-----------------------------------|
| `**/.wrangler/**` | Wrangler's generated local state. |
