Build Vitest coverage options whose thresholds come from `nova.config.json`.

## Summary

- Returns the `v8` provider with the `text-summary` and `json-summary` reporters, so a coverage run writes `coverage/coverage-summary.json`.
- Reads `settings.coverage.minimum` from the nearest `nova.config.json` above the workspace.
- With a minimum set, uses it for the `lines`, `functions`, `branches` and `statements` thresholds, so the run fails below it. Without one, the run reports coverage and never fails on it.

## Why Use This Battery?

1. Keeps one minimum for the whole project instead of a number copied into every Vitest config.
2. Writes the summary file the [publish workflow](/docs/cli/generators/github/workflows) turns into the README coverage badge.
3. Changing the minimum in `nova.config.json` takes effect on the next run without editing any Vitest config.

## Usage

```ts title="vitest.config.mts"
import { VitestCoverage } from '@cbnventures/nova/toolkit';
import { defineConfig } from 'vitest/config';

export default defineConfig({
  test: {
    include: ['src/**/*.test.ts'],
    globals: false,
    testTimeout: 30000, // 30 seconds.
    coverage: VitestCoverage.options(),
  },
});
```

```json title="package.json"
{
  "scripts": {
    "check:coverage": "vitest run --coverage"
  },
  "devDependencies": {
    "@vitest/coverage-v8": "4.1.12"
  }
}
```

Coverage only runs with `--coverage`. The `check:coverage` script runs the whole suite and writes the summary, and a failing test fails it too, so a package that has it needs no separate `check:test` script. Keep `@vitest/coverage-v8` on the same version as `vitest`.

```json title="nova.config.json"
{
  "settings": {
    "coverage": {
      "minimum": 80
    }
  }
}
```

## Settings

| Setting          | Type     | Default         | Description                                                       |
|------------------|----------|-----------------|-------------------------------------------------------------------|
| `startDirectory` | `string` | `process.cwd()` | Folder the search for the nearest `nova.config.json` starts from. |

A minimum that is not a number from 0 to 100 throws an error that names the config file.
