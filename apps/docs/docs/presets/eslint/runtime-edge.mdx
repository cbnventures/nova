Declare Web Worker-compatible globals for portable edge code. This avoids assuming a browser window, a Service Worker lifecycle, or Node.js APIs that an edge provider may not expose.

## Usage

```ts title="eslint.config.mts"
import {
  dxCodeStyle,
  dxIgnore,
  langTypescript,
  runtimeEdge,
} from '@cbnventures/nova/presets/eslint';

export default [
  ...dxIgnore,
  ...dxCodeStyle,
  ...langTypescript,
  ...runtimeEdge,
];
```

## What This Preset Configures

The preset applies the `globals` package's Worker environment to JavaScript, TypeScript, MJS, and MTS files. Provider-specific APIs and bindings remain consumer-owned.
