Inline glossary block that expands abbreviations in a tooltip on hover, keyboard focus, or tap. Wrap any text to add a tooltip with the expanded form.

Optionally links to a glossary page and supports a color accent.

## Summary

The Terminology block renders the term as a focusable inline `<abbr>` wrapper with a button role, or as a `<Link>` when `to` is provided, and shows the expanded form in its own tooltip. The tooltip opens on hover and keyboard focus on desktop and on tap on touch screens, and closes on mouse leave, blur, Escape, or a tap elsewhere. For a linked term, mouse and keyboard users open the page by clicking or pressing Enter on the term itself. On touch screens, the first tap opens the tooltip and a second tap opens the page.

The optional `color` prop adds a visual accent to distinguish glossary terms from regular text.

## Why Use This Block?

- **Abbreviation expansion** without leaving the page or breaking reading flow.
- **Linked glossary** — optionally navigate to a terminology page on click.
- **Works on every device** — the tooltip opens on hover, keyboard focus, and tap, and stays inside the screen.
- **Accessible** — the tooltip uses `role="tooltip"`, and the expanded form stays linked to the term through `aria-describedby` even while the tooltip is closed.
- **Preset-aware** — the color accent uses the active preset's primary color.

## Options

| Prop        | Type                         | Default     | Description                                                           |
|-------------|------------------------------|-------------|-----------------------------------------------------------------------|
| `children`  | `ReactNode`                  | —           | The text to wrap with a tooltip. Required.                            |
| `title`     | `string`                     | —           | Expanded abbreviation shown in the tooltip. Required.                 |
| `to`        | `string \| undefined`        | `undefined` | Link target. When set, renders as a `<Link>` that opens this path.    |
| `color`     | `boolean \| undefined`       | `undefined` | Set to `true` to add a color accent to the text.                      |
| `className` | `string \| undefined`        | `undefined` | Additional class names merged with the base `nova-terminology` class. |
| `style`     | `CSSProperties \| undefined` | `undefined` | Inline style overrides applied to the root element.                   |

## Troubleshooting

- **Tooltip not showing** — On desktop the tooltip opens after a short hover or focus delay. On touch screens, tap the term once.
- **Color accent** — The `color` prop adds the `nova-terminology-colored` CSS class. This is styled by the active preset.
- **Link not navigating** — Ensure the `to` prop points to a valid docs path. On touch screens the first tap opens the tooltip; tap the term again to open the page. Without `to`, the term only opens its tooltip.
