Declare the standard Worker globals available to Cloudflare Worker source files without exposing browser-window or Node.js-only names. Project-specific bindings such as `env` remain typed by the consumer.

## Usage

```ts title="eslint.config.mts"
import {
  dxCodeStyle,
  dxIgnore,
  langTypescript,
  runtimeCloudflareWorkers,
} from '@cbnventures/nova/presets/eslint';

export default [
  ...dxIgnore,
  ...dxCodeStyle,
  ...langTypescript,
  ...runtimeCloudflareWorkers,
];
```

## What This Preset Configures

The preset applies the `globals` package's Worker environment to JavaScript, TypeScript, MJS, and MTS files. Add binding types through your own declarations or generated Wrangler types.
