Declare Web Worker globals for background JavaScript and TypeScript without making browser-window or Node.js APIs available to ESLint.

## Usage

```ts title="eslint.config.mts"
import {
  dxCodeStyle,
  dxIgnore,
  langTypescript,
  runtimeWebWorker,
} from '@cbnventures/nova/presets/eslint';

export default [
  ...dxIgnore,
  ...dxCodeStyle,
  ...langTypescript,
  ...runtimeWebWorker,
];
```

## What This Preset Configures

The preset applies the `globals` package's Worker environment to JavaScript, TypeScript, MJS, and MTS files.
