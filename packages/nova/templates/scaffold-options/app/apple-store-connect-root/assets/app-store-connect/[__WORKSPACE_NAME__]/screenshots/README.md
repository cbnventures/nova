# App Store Screenshots

Create only the targets you intend to replace:

```text
ios/<locale>/iphone/01-name.png
ios/<locale>/iphone-duo/01-name.png
ios/<locale>/ipad/01-name.png
ios/<locale>/apple-watch/01-name.png
macos/<locale>/mac/01-name.png
```

Names begin with positions `01` through `10`. Nova leaves absent targets untouched and rejects an existing empty target directory.
