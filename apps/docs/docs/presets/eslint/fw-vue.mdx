Lint Vue single-file components through a Nova-owned compatibility layer.

## Why Use This Preset?

1. Selects Vue's official flat-config correctness baseline without copying its entire project setup.
2. Parses TypeScript inside `.vue` components through Nova's installed TypeScript parser.
3. Composes after Nova's required ignore, code-style, and language layers.
4. Leaves consumer-specific rule changes in a later config block.

## Usage

```ts title="eslint.config.mts"
import {
  dxCodeStyle,
  dxIgnore,
  fwVue,
  langJavascript,
  langTypescript,
  runtimeBrowser,
  toolVite,
} from '@cbnventures/nova/presets/eslint';
import { novaRules } from '@cbnventures/nova/rules/eslint';

export default [
  ...dxIgnore,
  ...dxCodeStyle,
  ...langJavascript,
  ...langTypescript,
  ...runtimeBrowser,
  ...toolVite,
  ...fwVue,
  ...novaRules,
];
```
