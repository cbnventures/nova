Terminal window around command-line output. The window looks like macOS Terminal: a white title bar with traffic lights, the folder icon, and a left-aligned title, then a black body in SF Mono.

## Summary

The Terminal Frame block renders a `<figure class="nova-terminal-frame">` with the title bar and a `<pre>` body that holds your output as text. Text stays sharp at any zoom and needs no screenshot files. Every size was measured from a real 80-column Terminal window and scales with the frame's width, so the window keeps its proportions on any screen.

## Why Use This Block?

- **Real output, no images** — paste the actual text your CLI prints; nothing goes stale the way a screenshot does.
- **Real proportions** — the title bar, lights, and font size match an 80x24 Terminal window.
- **Built-in line tones** — pass one element per line and pick a tone class for each, so captured output is colored without any site CSS.

## Usage

Children can be plain text with newlines:

```tsx title="src/pages/index.tsx"
import { TerminalFrame } from '@cbnventures/docusaurus-preset-nova/blocks';

<TerminalFrame title="project — mytool — 80×24" label="mytool's main menu">
  {[
    '? What would you like to do? › - Use arrow-keys. Return to submit.',
    '❯   Add',
    '    Edit',
    '    Exit',
  ].join('\n')}
</TerminalFrame>
```

Or one element per line, each with a [line tone](#line-tones) class:

```tsx title="src/pages/index.tsx"
<TerminalFrame title="project — mytool deploy — 80×24" label="mytool deploy output">
  <span className="nova-terminal-frame-line-prompt">$ mytool deploy</span>
  <span className="nova-terminal-frame-line-heading">Deploying mytool</span>
  <span className="nova-terminal-frame-line-info">→ Building 12 pages</span>
  <span className="nova-terminal-frame-line-body">  Uploaded 12 files to the server.</span>
  <span className="nova-terminal-frame-line-muted">  Finished in 3.2s</span>
</TerminalFrame>
```

## Options

| Prop        | Type                         | Default     | Description                                                              |
|-------------|------------------------------|-------------|--------------------------------------------------------------------------|
| `children`  | `ReactNode`                  | —           | The output: text with newlines, or one element per line. Required.       |
| `title`     | `string`                     | —           | Window title, Terminal style (`folder — command — 80×24`). Required.     |
| `label`     | `string \| undefined`        | `undefined` | Accessible label for the output, read by screen readers.                 |
| `className` | `string \| undefined`        | `undefined` | Additional class names merged with the base `nova-terminal-frame` class. |
| `style`     | `CSSProperties \| undefined` | `undefined` | Inline style overrides applied to the outer `<figure>` element.          |

## Line Tones

Give each line element one of these classes to color captured CLI output. The body is always black, so each tone looks the same in light and dark mode.

| Class                              | Description                                         |
|------------------------------------|-----------------------------------------------------|
| `nova-terminal-frame-line-info`    | Soft blue-gray (`#8aa0b4`) for status and progress. |
| `nova-terminal-frame-line-prompt`  | Green (`#7ad67a`) for prompts and typed commands.   |
| `nova-terminal-frame-line-muted`   | Dim gray (`#6f7f8f`) for hints and timings.         |
| `nova-terminal-frame-line-heading` | Bold white (`#ffffff`) for section headings.        |
| `nova-terminal-frame-line-body`    | Light gray (`#d4d4d4`) for regular output.          |

Lines without a tone class stay white.

## Width

The window is drawn as an 80-column Terminal 890pt wide. To match a window of another width, set `--nova-terminal-frame-width` (in points) through `style`.
