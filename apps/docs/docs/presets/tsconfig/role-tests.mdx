Use `role-tests` for Vitest suites, fixtures, and test-only helpers.

## Why Use This Preset?

1. Keeps test code under the same strict type-checking baseline as production code.
2. Prevents test JavaScript and declaration files from leaking into build output.
3. Leaves test globals and environment types explicit in each project instead of assuming one runner or runtime.

## Usage

```json title="tsconfig.tests.json"
{
  "extends": [
    "@cbnventures/nova/presets/tsconfig/dx-essentials.json",
    "@cbnventures/nova/presets/tsconfig/dx-strict.json",
    "@cbnventures/nova/presets/tsconfig/role-tests.json",
    "@cbnventures/nova/presets/tsconfig/runtime-node.json"
  ],
  "compilerOptions": {
    "types": [
      "@types/node",
      "vitest/globals"
    ]
  }
}
```

## What This Preset Configures

| Setting          | Value   | Description                                 |
|------------------|---------|---------------------------------------------|
| `declaration`    | `false` | Does not create declarations for test code. |
| `declarationMap` | `false` | Does not create declaration maps.           |
| `noEmit`         | `true`  | Checks tests without writing build output.  |
